How it works Pipeline Source code

Every new lead is read, scored, logged and answered in under ten seconds.

LeadPilot is a working AI automation built with n8n, LangChain, a Groq-hosted GPT-OSS model, Gmail and Google Sheets. Fill in the form as if you were a client and watch each step run.

Replies are saved as Gmail drafts for a person to review. Nothing is emailed to you automatically.

        Five workflows run behind the form
        
      
        Each one is an n8n workflow you can import from the repository. Together they cover the full lead lifecycle, from first contact to the morning briefing.
        

      
        
        
        
          
        Lead intake and qualification
        
          
        Validates the submission, asks the LLM for intent, fit and a personal reply, blends that with rule-based signals into one score, appends the lead to the Sheets CRM, saves a Gmail draft and emails the owner when a lead is hot.
        
          
        WebhookCodeLLM ChainGroqGoogle SheetsGmail
        
        
        
        
        
          
        Inbox triage agent
        
          
        An AI agent watches Gmail. It looks the sender up in the CRM, classifies the email, updates the lead's status and drafts a threaded reply. It has tools, not permission to send.
        
          
        Gmail triggerLangChain AI AgentSheets toolsGmail tool
        
        
        
        
        
          
        Morning pipeline briefing
        
          
        Every weekday at 07:30 it reads the CRM, works out what changed, finds hot leads nobody has contacted and emails a short AI-written briefing.
        
          
        ScheduleGoogle SheetsLLM ChainGmail
        
        
        
        
        
          
        CRM API
        
          
        A read-only endpoint that powers the public pipeline page. Names are cut to first names and emails are masked before anything leaves n8n.
        
          
        WebhookGoogle SheetsCode
        
        
        
        
        
          
        Failure alerts
        
          
        If any workflow fails, an error workflow emails the owner the workflow name, failing node, message and a link to the execution.
        
          
        Error triggerGmail
        
        
        
      
        
    
        

    
        
      
        Decisions worth explaining
        
      
        
        
        
          
        A person approves every email
        
          
        The AI writes replies as drafts. Auto-sending from a public form would let anyone use the mailbox to email strangers, and a five-second review keeps the tone right.
        
        
        
        
        
          
        The score is part AI, part rules
        
          
        The AI judges intent and fit for 65% of the score. Budget, timeline, business email and detail make up the rest, so the number stays stable and a salesperson can see why it moved.
        
        
        
        
        
          
        No secrets in the browser
        
          
        The site talks to a Vercel function, which validates input, limits bursts and calls n8n with a shared header key. AI and Google credentials live only inside n8n.
        
        
        
        
        
          
        One failed step doesn't lose the lead
        
          
        CRM and Gmail steps continue on error, so the visitor still gets a result and the error workflow tells the owner what to fix.
